# Aarya's Portfolio — AI Filmmaker & VFX Specialist

> *"Directing Pixels. Crafting Cinema with AI."*

A luxury, ultra-smooth scrolling portfolio website for **Aarya Bhujade** (@aarya_x_apertures), AI Filmmaker, AI Artist & VFX Specialist (ADVFX+ MAAC Mumbai // AAFT Photography).

## Highlights & Architecture
- **Interactive Canvas Frame-Sequence Scrubber:** GSAP ScrollTrigger + Lenis smooth scroll scrubbing an ultra-smooth 115-frame WebP sequence across a Retina/DPR full-viewport HTML5 canvas.
- **Cinematic Visual Aesthetic:** Smoky obsidian atmosphere (`#07080B`), warm golden-amber volumetric illumination, 35mm celluloid filmstrip ribbons, and dark smoked frosted-glass cards (`backdrop-filter: blur(12px)`).
- **Curated Archive:** Client commercial campaigns, broadcast television promos, original Gen-AI films, music films, vertical Instagram reels deck, and comic chronicles.
- **Performance:** Instant priority frame preloading with minimal HUD telemetry, pure relative asset referencing, and zero external dependency failures.

## Tech Stack
- **Smooth Scroll & Animation:** Lenis, GSAP, ScrollTrigger
- **Media & Canvas:** HTML5 Canvas, WebP frame sequences, H.264 video streams
- **Typography:** Cinzel, Cormorant Garamond, Plus Jakarta Sans, Space Grotesk, JetBrains Mono
- **Deployment:** GitHub Pages
